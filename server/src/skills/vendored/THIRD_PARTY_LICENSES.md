# Third-Party Licenses — Vendored Skills

This directory vendors skill content from upstream MIT-licensed
GitHub repositories into Code Siren so the server boots from the
repo instead of fetching from the network at startup. Each skill is
pinned to a specific upstream commit SHA (recorded in `MANIFEST.json`).

Upstream licenses are reproduced verbatim in each repo's `LICENSE`
file under its subdirectory. A summary follows.
